FIXES APPLIED BY CLANCY (marked in the files)
  1. run_demo.sh — removed the `pip install` line. Deps are already in
     the project venv, and there is no `pip` binary in this venv
     (installs go through `uv pip install`), so the line would fail.
  2. run_demo.sh — added PYTHONPATH=. to the pytest call. The `pytest`
     binary does not put the working directory on sys.path, so
     `from src.app import app` failed with ModuleNotFoundError inside
     the demo (standalone `python -m pytest` runs had passed only
     because `python -m` adds CWD). This was a real defect: the demo
     script's own QA step was broken until the fix.
  3. openapi.yaml — the hand-written spec had empty {} schemas for all
     five 422 responses, but the live /openapi.json uses
     $ref HTTPValidationError. Replaced all five with the $ref and
     added the HTTPValidationError + ValidationError components copied
     verbatim from the live schema. (One misstep during the fix: the
     first patch wrote the key as \$ref; caught by re-reading the
     parsed YAML and fixed to $ref before verification.)
  4. SOP.md — closed an unclosed ```bash code fence after the uvicorn
     start command.
  5. README.md — fixed the unclosed ```bash fence and completed the
     truncated "How to Run" section (manual server start + test-only
     command were cut off mid-file).
  6. Environment — installed pyyaml in the project venv (the
     conformance test imports yaml; it was not installed).
