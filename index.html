Proof of work: Hacker News front-page pipeline

Headless Playwright extraction of the live Hacker News top 30 — rank, title, domain, points, submitter, and comment count — by pairing title rows and detail rows in the DOM without fragile XPaths. Pandas enforces strict types before exporting hn_top30.csv, ready to load into PostgreSQL.

Verified 2026-11-12: 6/6 pytest tests passing — exactly 30 rows, no nulls or blanks in rank/title, integer types for rank/points/comment count, submitter populated on every row, and no empty values except domain (Ask HN / text posts legitimately have none).

The part that matters: independent verification caught a defect the first test suite missed — the original submitter selector relied on a CSS class (.hnuser) no longer present on live Hacker News, leaving the submitter column empty. I fixed it with a structural attribute selector (a[href^="user?id="]) and added tests so that failure cannot pass silently again.

Proof of work: Webhook-to-CRM sync microservice

A FastAPI microservice that replaces a fragile Zapier zap: it receives contact-form webhooks, validates them with Pydantic, deduplicates by email, forwards each new contact to the downstream CRM, and logs every sync to SQLite — so no lead ever disappears silently.

Verified 2026-11-12: 6/6 pytest tests passing — valid submission syncs, invalid email and missing fields rejected with 422, duplicate email returns the original contact without calling the CRM twice, downstream failure returns 502 and is logged as failed.

Verified live against the real JSONPlaceholder CRM endpoint: a live submission returned 201 with crm_id 11, a repeat of the same email returned 200 duplicate, and the sync log held exactly one row. The part that matters: verification caught a real bug the first test run missed — failed submissions were never written to the log, because the error path rolled the insert back. Fixed with an explicit commit before raising the 502, and the live run proved the fix.
