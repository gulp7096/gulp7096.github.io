FIXES APPLIED BY CLANCY (marked in the files)
  1. src/app.py — added conn.commit() after the failed-row INSERT, before
     raising the 502. Without it, the HTTPException unwound the sqlite
     `with` block and the failed row rolled back, so downstream failures
     were never logged (the brief requires them to be). This was a real
     bug: the downstream-failure test failed (0 rows in the log) until
     the fix.
  2. tests/test_app.py — replaced AsyncMock return-value attribute setup
     (mock_post.return_value.json.return_value = ...) with real
     httpx.Response objects including an attached request. The mock
     setup made .json() and .raise_for_status() async, so resp.json()
     returned an un-awaited coroutine (AttributeError: 'coroutine'
     object has no attribute 'get'). Real Response objects fixed it.
  3. run_demo.sh — exports a clean NO_PROXY ("localhost,127.0.0.1").
     This VM's NO_PROXY contains bracketed IPv6 literals that httpx
     cannot parse (InvalidURL: Invalid port: ':1]'), which broke every
     test that constructs an httpx client. Same class of VM-egress
     quirk as the Playwright relay patch.
  4. README.md — fixed the test command (it pointed at
     tests/verify_deliverable.py; the suite is tests/test_app.py) and
     closed an unclosed ```bash code fence.
  5. Environment — installed email-validator in the project venv
     (pydantic[email] requires it; it was not installed).
